# Frozen inputs, data attribution and older diagnostics

The reference artifact download includes the exact ProMeta inputs used in the verified publication studies:

- Raw PROTAC-DB export; sequence-audited CRBN/VHL contexts and their component table.
- Fixed ESM-2 feature bank and existing sequence-resolution/context audits.
- Rare-E3 target contexts, compound-grouped exhaustive splits and source/target mappings.
- Linker whole-molecule/warhead/recruiter/linker structures, identities and measured labels from the curated SE(3)-PROTACs series selection.
- HPK1/FLT3 family contexts and original ProMeta query scores.
- CDK6 structures, labels, all 33 support pairs, the fixed split, three checkpoints and original prediction tables.
- ProMeta-only workload tensors and original timing records.

Molecular data are attributed through their frozen DOI/source columns and source-study publications; the repository's MIT license applies to ProMeta code, not an invented replacement license for upstream datasets. Keep database and source publication citations when using these inputs.

Source training relies on fixed protein features. The 650M ESM-2 feature-producing network is not loaded into the online ProMeta predictor. Entirely new proteins require matching feature extraction before inference.

The final sequence-audited table contains 1,325 contexts (808 CRBN/517 VHL). Earlier 1,386-context and 1,509-row sequence tables are different preprocessing records. The historical manuscript S1 stage ordering and older scaffold/UMAP pictures do not supply a fully audited current-model image-generation pipeline; this release does not manufacture such provenance.

Two small `results/legacy_*_recomputed.csv` files preserve ProMeta-only older RDKit 3D and intersection-trained summaries. They come from an earlier GCN/fingerprint implementation, are not generated by the current GNN/protein/interaction encoder, and are not used as current source checkpoints. The DM-latent prototype diagnostic is excluded because it is a comparator representation, not ProMeta. No comparator code or model weights are distributed here.

The updated CDK6 case bundle received on October 19 supplies three ProMeta checkpoints and the original evaluation split. Its prediction tables and support/member lists are byte-identical to the previously released references. Only the ProMeta weights and split were added to this publication artifact, with archive provenance in `cdk6/checkpoint_provenance.json`; unrelated figures and comparator outputs were not imported. The checkpoint-based inference validation recovers the paper case result from all 1,188 queries.
